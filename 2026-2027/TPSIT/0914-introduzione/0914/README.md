# Registro di classe - 4A INF

Questo progetto è un semplice registro scolastico creato come esercitazione di TPSIT per la classe 4A INF.

## Obiettivo

L'applicazione mostra un elenco di studenti con:
- nome
- stato di presenza
- pulsante per giustificare un'assenza
- ricerca filtrata tra gli studenti
- riepilogo dei presenti/assenti
- reindirizzamento a una seconda pagina

## Funzioni implementate

- Visualizzazione di un elenco di studenti
- Memorizzazione delle presenze in un array
- Gestione del bottone "Giustifica" per trasformare un assente in presente
- Filtro rapido tramite campo di ricerca
- Apertura di una finestra di riepilogo con numero di presenti e assenti
- Reindirizzamento a una seconda pagina HTML

## Struttura del progetto

- `index.html` - pagina principale del registro
- `index.css` - stili della pagina
- `index.js` - logica JavaScript del progetto
- `pagina-2.html` - pagina secondaria raggiungibile tramite redirect

## Come usare il progetto

1. Apri il file `index.html` in un browser.
2. Troverai la lista degli studenti con lo stato delle presenze.
3. Puoi usare la barra di ricerca per filtrare gli studenti.
4. Premi "Giustifica" per segnare un'assenza come giustificata.
5. Premi "Riepilogo" per vedere quanti studenti sono presenti o assenti.
6. Premi "Redirect" per aprire la pagina secondaria.

## Note

Questo progetto è pensato come esercitazione didattica per imparare:
- array e cicli
- manipolazione del DOM
- eventi JavaScript
- ricerca e filtraggio
- gestione delle presenze
