## Purpose

This repository is used to organize study material, exercises and projects during my school years. It documents my learning progress and provides a collection of practical code examples and learning resources.

## Running Projects

Each project is independent and must be opened or executed from its own directory.

- Web: Open `index.html` in a browser.
- C: Compile the `.c` file using a compiler such as GCC.
- C#: Open the project or solution in Visual Studio.
- Python: Run the `.py` file using Python.
